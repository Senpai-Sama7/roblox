Core Mechanics

This browser-based simulation runs the same logic as the Roblox server: checkpoint validation, combo timing, coin distance checks, and finish-line gating. Every mechanic is authoritatively validated.

  • Sequential checkpoint validation (no skips)
  • 8-second combo window with tiered multipliers
  • Distance-based coin collection
  • Anti-cheat velocity checks
  • Per-type touch debouncing
  • Real-time HUD with timer and progress
